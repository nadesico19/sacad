# Sacad Tutorial

> **AI-generated documentation:** This tutorial was generated by **OpenAI GPT-5 Codex** from the current Sacad Python source. It should be reviewed when the public API or the managed AutoCAD plug-in changes.

This tutorial introduces practical Sacad workflows, from generating entities and styles to building reusable templates and saving completed drawings. All examples use generic names and data so they can be adapted independently.

Sacad requires Windows, AutoCAD, `pywin32`, NumPy, and a compatible build of `SacadMgd.dll`. The examples assume that Sacad can already connect to AutoCAD.

## Discover AutoCAD and manage a session

Sacad can discover supported AutoCAD installations, target a specific version, start it when necessary, and close the Sacad session automatically. Activate AutoCAD before operations that prompt the user.

```python
import sacad as ac

versions = ac.Acad.get_available()
if not versions:
    raise RuntimeError("No supported AutoCAD installation was found.")

with ac.instant_acad(acad_name=versions[-1]) as cad:
    print("Connected to AutoCAD", cad.name)
    cad.activate()
```

`instant_acad()` is convenient for one-shot scripts. For a longer-lived integration, create an `Acad` instance and manage its lifecycle explicitly:

```python
import sacad as ac

cad = ac.Acad(acad_name=ac.ACAD_LATEST)
try:
    cad.open()
    print("Connected to AutoCAD", cad.name)
finally:
    cad.close()
```

Use `sta=True` when COM must be initialized as a single-threaded apartment for work performed by a background thread:

```python
with ac.instant_acad(acad_name=ac.ACAD_LATEST, sta=True) as cad:
    operation = cad.db_insert()
    operation.model_space.insert(ac.Line.new(0, 0, 100, 0))
    operation.submit()
```

## Generate entities and styles

Entities and named drawing resources are ordinary Python objects. They can be assembled in an in-memory `Database` before AutoCAD is opened. The following example creates a linetype, a layer, text and dimension styles, and several entities that use those styles.

```python
import sacad as ac

db = ac.Database()

db.linetype_table["DASHED_SAMPLE"] = ac.LinetypeTableRecord(
    name="DASHED_SAMPLE",
    comments="Generated by Sacad",
    pattern_length=12.0,
    segments=[
        ac.LinetypeSegment(dash_length=8.0),
        ac.LinetypeSegment(dash_length=-4.0),
    ],
)
db.layer_table["OUTLINE"] = ac.LayerTableRecord(
    name="OUTLINE",
    color=ac.Color.index(3, ac.ColorMethod.BY_ACI),
    linetype="DASHED_SAMPLE",
    line_weight=ac.LineWeight.LINE_WEIGHT_025,
)
db.text_style_table["LABEL"] = ac.TextStyleTableRecord(
    name="LABEL",
    file_name="txt.shx",
    text_size=0.0,
    x_scale=1.0,
)
db.dim_style_table["DIM_SAMPLE"] = ac.DimStyleTableRecord(
    name="DIM_SAMPLE",
    dimscale=1.0,
    dimtxt=2.5,
    dimasz=2.5,
    dimtxsty="LABEL",
)

model_space = db.get_block(ac.MODEL_SPACE)
model_space.entities.extend([
    ac.Line.new(0, 0, 100, 0, layer="OUTLINE"),
    ac.Circle.new(50, 25, 12, layer="OUTLINE"),
    ac.Polyline.new(
        ac.Vertex.new(0, 0),
        ac.Vertex.new(100, 0),
        ac.Vertex.new(100, 50),
        ac.Vertex.new(0, 50),
        closed=True,
        layer="OUTLINE",
    ),
    ac.DBText.new(
        50,
        60,
        "SAMPLE",
        ac.AttachmentPoint.MIDDLE_CENTER,
        height=5,
        text_style_name="LABEL",
    ),
    ac.AlignedDimension.new(
        0,
        0,
        100,
        0,
        0,
        -15,
        dimension_style_name="DIM_SAMPLE",
    ),
])
```

Common entity properties can be supplied as keyword arguments. These include `layer`, `linetype`, `linetype_scale`, `color`, `color_index`, `line_weight`, and `visible`.

## Insert a complete drawing in one batch

`replace_db()` attaches a prepared database to an insertion operation. Styles, blocks, groups, and model-space entities are transferred together. An explicit insertion point can be supplied, or AutoCAD can prompt the user for one.

```python
import sacad as ac

with ac.instant_acad() as cad:
    operation = cad.db_insert(
        prompt_insertion_point=True,
        upsert=True,
        zoom_mode=ac.ZoomMode.ADDED,
        zoom_factor=1.25,
    )
    operation.replace_db(db)
    cad.activate()
    result = operation.submit()

print(result.status, result.num_inserted, result.num_updated)
```

For non-interactive placement, replace `prompt_insertion_point=True` with an explicit point:

```python
operation = cad.db_insert(insertion_point=ac.Vector3d(250, 100, 0))
operation.replace_db(db)
result = operation.submit()
```

Creating an operation does not modify AutoCAD. The complete request is executed only when `submit()` is called.

## Extract and reuse entities and styles

Model-space entities and style tables can be read from the active drawing, serialized, and reused later. This supports reusable style libraries and drawing fragments without requiring a live AutoCAD session while the saved data is being processed.

```python
from pathlib import Path
import sacad as ac

flags = (
    ac.TableFlags.MODEL_SPACE
    | ac.TableFlags.TEXT_STYLE
    | ac.TableFlags.LINETYPE
    | ac.TableFlags.LAYER
    | ac.TableFlags.DIM_STYLE
    | ac.TableFlags.M_LEADER_STYLE
)

with ac.instant_acad() as cad:
    extracted = cad.db_get_tables(flags).submit().db

library_path = Path("drawing-library.json")
library_path.write_text(extracted.serialize(indent=2), encoding="utf-8")
```

Load the serialized resources and insert them into the active drawing:

```python
reusable_db = ac.Jsonify.deserialize(
    library_path.read_text(encoding="utf-8")
)

with ac.instant_acad() as cad:
    operation = cad.db_insert(upsert=True)
    operation.replace_db(reusable_db)
    result = operation.submit()
```

When `upsert=True`, existing named resources are updated where supported. Otherwise, resources with names already present in the drawing are left unchanged.

Named blocks can be extracted separately. In the current implementation, pass the names explicitly:

```python
with ac.instant_acad() as cad:
    result = cad.db_get_tables(
        ac.TableFlags.BLOCKS,
        block_names=["SYMBOL_A", "SYMBOL_B"],
    ).submit()
    reusable_blocks = result.db.block_table
```

An empty `block_names` list or `None` returns no block definitions in the current managed implementation.

## Define and reuse blocks

A `BlockTableRecord` stores a named component definition. Insert a matching `BlockReference` into model space to place the component repeatedly with different positions, rotations, and scale factors.

```python
import math
import sacad as ac

db = ac.Database()
db.block_table["MARKER"] = ac.BlockTableRecord(
    name="MARKER",
    entities=[
        ac.Circle.new(0, 0, 5),
        ac.Line.new(-7, 0, 7, 0),
        ac.Line.new(0, -7, 0, 7),
    ],
)

db.get_block(ac.MODEL_SPACE).entities.extend([
    ac.BlockReference(
        name="MARKER",
        position=ac.Vector3d(20, 20, 0),
    ),
    ac.BlockReference(
        name="MARKER",
        position=ac.Vector3d(80, 20, 0),
        rotation=math.pi / 4,
        scale_factors=ac.Vector3d(2, 2, 1),
    ),
])

with ac.instant_acad() as cad:
    operation = cad.db_insert(upsert=True)
    operation.replace_db(db)
    operation.submit()
```

`BlockTableRecord` is also a useful serializable envelope for a standalone entity collection, even when it is not inserted as a named block.

## Build text-replacement drawing templates

A drawing template can be stored as a serialized `Database` whose `DBText`, `MText`, or dimension text contains placeholders. Load the template, replace the placeholders, and insert the rendered database. Because styles and block definitions can live in the same database, the template can be self-contained.

```python
from pathlib import Path
import sacad as ac


def replace_tokens(value, values):
    if value is None:
        return None
    for name, replacement in values.items():
        value = value.replace("<{}>".format(name), str(replacement))
    return value


template = ac.Jsonify.deserialize(
    Path("drawing-template.json").read_text(encoding="utf-8")
)
values = {
    "TITLE": "General Arrangement",
    "DRAWING_NO": "A-001",
    "REVISION": "B",
}

for block in template.block_table.values():
    for entity in block.entities:
        if isinstance(entity, ac.DBText):
            entity.text_string = replace_tokens(entity.text_string, values)
        elif isinstance(entity, ac.MText):
            entity.contents = replace_tokens(entity.contents, values)
        elif isinstance(entity, ac.Dimension):
            entity.dimension_text = replace_tokens(
                entity.dimension_text,
                values,
            )

with ac.instant_acad() as cad:
    operation = cad.db_insert(prompt_insertion_point=True, upsert=True)
    operation.replace_db(template)
    cad.activate()
    operation.submit()
```

To create the template JSON from the active drawing, retrieve model space and the required resource tables, then serialize the returned database as shown in the previous section.

Placeholders can also be authored by selecting existing text and dimension entities, editing their text properties in Python, inserting the edited entities, and deleting the originals as demonstrated below.

## Save the current drawing as a DWG

Sacad currently has no dedicated DWG-export database query. After submitting the drawing content, use the AutoCAD application object exposed by `Acad.com` to save the active document. An absolute `.dwg` path is recommended.

```python
from pathlib import Path
import sacad as ac

output_path = Path("output.dwg").resolve()

with ac.instant_acad() as cad:
    operation = cad.db_insert()
    operation.replace_db(db)
    operation.submit()

    document = cad.com.app.ActiveDocument
    document.SaveAs(str(output_path))
```

`SaveAs` acts on the entire active AutoCAD document. It is a document-level ActiveX operation rather than a Sacad database batch operation. The active document must be the document intended for export.

## Operate on user-selected entities

Sacad can read either the pick-first selection or a selection requested through an AutoCAD prompt.

```python
import sacad as ac

with ac.instant_acad() as cad:
    selection = cad.db_get_user_selection(by_prompt=True)
    cad.activate()
    selected_db = selection.submit().db
    selected = selected_db.get_block(ac.MODEL_SPACE).entities

    for entity in selected:
        print(type(entity).__name__, entity.id)
```

Use `by_prompt=False` to read AutoCAD's current pick-first selection. Set `explode_blocks=True` when selected block references should be returned as their component entities:

```python
selection = cad.db_get_user_selection(
    by_prompt=True,
    explode_blocks=True,
)
result = selection.submit()
```

Selection results preserve AutoCAD object IDs for supported entities, allowing later deletion of the original objects.

## Replace existing entities

Insertion creates new AutoCAD objects even when the Python entities originated from a selection. To replace existing content, submit the replacements first and delete the original object IDs only after insertion succeeds.

```python
import sacad as ac

with ac.instant_acad() as cad:
    selection = cad.db_get_user_selection(by_prompt=True)
    cad.activate()
    original_db = selection.submit().db
    originals = original_db.get_block(ac.MODEL_SPACE).entities

    replacements = [entity.clone() for entity in originals]
    for entity in replacements:
        if isinstance(entity, ac.DBText):
            entity.text_string = "REPLACED"

    insertion = cad.db_insert()
    insertion.model_space.insert_many(replacements)
    insertion.submit()

    deletion = cad.db_delete()
    deletion.query.database.get_block(
        ac.MODEL_SPACE
    ).entities.extend(originals)
    deletion.submit()
```

The insert and delete calls are separate AutoCAD transactions. Retain the original serialized selection until both operations complete if recovery may be required.

## Create, retrieve, and delete entity groups

`insert_and_ref()` assigns temporary identities that allow newly inserted entities to be referenced by a `Group` in the same database request.

```python
import sacad as ac

with ac.instant_acad() as cad:
    insertion = cad.db_insert()
    first_id = insertion.model_space.insert_and_ref(
        ac.Line.new(0, 0, 100, 0)
    )
    second_id = insertion.model_space.insert_and_ref(
        ac.Line.new(100, 0, 100, 50)
    )
    insertion.query.database.group_dict["COMPONENT_A"] = ac.Group(
        name="COMPONENT_A",
        entity_ids=[first_id, second_id],
        selectable=True,
    )
    insertion.submit()
```

Retrieve a named group and its associated model-space entities:

```python
with ac.instant_acad() as cad:
    grouped = cad.db_get_groups("COMPONENT_A").submit().db

group = grouped.group_dict["COMPONENT_A"]
entities = grouped.get_block(ac.MODEL_SPACE).entities
print(group.name, len(group.entity_ids), len(entities))
```

Delete the group and, optionally, the entities it contains:

```python
with ac.instant_acad() as cad:
    deletion = cad.db_delete(delete_group_entities=True)
    deletion.delete_group("COMPONENT_A")
    result = deletion.submit()

print(result.num_deleted)
```

Omit `delete_group_entities=True` to remove the group while retaining its entities.

## Calculate AutoCAD-dependent entity properties

Some properties, including reliable geometric extents and adjusted text alignment, require AutoCAD. `db_test_entities()` converts candidate entities inside AutoCAD and returns the evaluated forms without inserting them into the drawing.

```python
import sacad as ac

candidates = [
    ac.DBText.new(
        0,
        0,
        "EXTENTS TEST",
        ac.AttachmentPoint.MIDDLE_CENTER,
        height=5,
    ),
    ac.Circle.new(25, 10, 8),
]

with ac.instant_acad() as cad:
    test = cad.db_test_entities()
    test.tested_entities.insert_many(candidates)
    evaluated_db = test.submit().db

for entity in evaluated_db.get_block(ac.MODEL_SPACE).entities:
    if entity.geometric_extents is not None:
        print(
            entity.geometric_extents.min_point,
            entity.geometric_extents.max_point,
        )
```

`Extents3d.is_valid()` can be used to reject empty or reversed extents before they are used for placement calculations.

## Transform and arrange reusable geometry

`Matrix3d` transformations can be composed and attached to any entity. This makes it possible to reuse one entity set at different scales, rotations, mirror states, and positions.

```python
import sacad as ac

source_entities = [
    ac.Line.new(0, 0, 40, 0),
    ac.Circle.new(20, 10, 5),
]

matrix = (
    ac.Matrix3d.identity()
    .scale(0.5, mirror_x=True)
    .rotate(90)
    .move(120, 80)
)

placed_entities = [entity.clone() for entity in source_entities]
for entity in placed_entities:
    entity.transform_by(matrix)

with ac.instant_acad() as cad:
    insertion = cad.db_insert()
    insertion.model_space.insert_many(placed_entities)
    insertion.submit()
```

The same transformation can be applied to `Vector2d` and `Vector3d` values with `vector.transform_by(matrix)`.

## Serialize drawing and layout data

All Sacad database and geometry types inherit `Jsonify`. Custom dataclasses can do the same when a small serializable configuration model is useful.

```python
from dataclasses import dataclass, field
from typing import List
import sacad as ac


@dataclass
class SheetLayout(ac.Jsonify):
    name: str
    origins: List[ac.Vector2d] = field(default_factory=list)


layout = SheetLayout(
    name="SHEET-01",
    origins=[ac.Vector2d(0, 0), ac.Vector2d(420, 0)],
)
json_text = layout.serialize(indent=2)
restored = SheetLayout.deserialize(json_text)
```

Serialized custom objects contain their full module and class names. The defining module must therefore be importable wherever such an object is reconstructed. Keeping transferable drawing payloads limited to Sacad types avoids dependencies on unrelated packages.

For dictionary-based transports, use `to_jsonify_dict()` and `from_jsonify_dict()`:

```python
payload = db.to_jsonify_dict()
restored_db = ac.Database.from_jsonify_dict(payload)
```

## Inspect operation results and handle failures

Every operation returns a result with a `Status` and optional message. Specialized result types also expose operation-specific values.

```python
import sacad as ac

with ac.instant_acad() as cad:
    operation = cad.db_insert()
    operation.model_space.insert(ac.Line.new(0, 0, 100, 0))
    result = operation.submit()

if result.status != ac.Status.SUCCESS:
    raise RuntimeError(result.message or "AutoCAD operation failed")

print("Inserted:", result.num_inserted)
print("Updated:", result.num_updated)
print("Failed:", result.num_failure)
```

`DBInsertResult` includes insertion, update, and failure counts plus a prompted insertion point when applicable. `DBSelectResult` contains a returned `Database`, and `DBDeleteResult` contains the deletion count. Operation objects also provide `cancel()` for cancelling an active request.

## Current limitations

- Sacad is Windows-specific and requires AutoCAD plus a compatible managed plug-in build.
- The current source maps AutoCAD releases from 2010 through 2023 and provides `ACAD_LATEST`.
- Model space is supported; paper space is not currently exposed by the Python object model.
- Lightweight `Polyline` is supported. `Polyline2d`, `Polyline3d`, `Ray`, `Spline`, and `Xline` are currently placeholders rather than implemented entities.
- Sacad is not a standalone DWG writer. A live AutoCAD document is required to execute database operations and save a DWG.
- `submit()` is synchronous. GUI applications should run blocking submissions outside their UI thread when appropriate.
- Prompted selection and insertion are interactive; activate AutoCAD before submitting those operations.
- `open(netload=True)` invokes `NETLOAD`, which can clear AutoCAD's implied selection. If the managed module is already loaded and a pick-first selection must be preserved, use `netload=False`.
